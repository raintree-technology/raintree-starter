# Next Starter logo system

The symbol evolves the repository's existing Raintree-adjacent tree motif into a more compact product mark. Its stepped outer silhouette represents modular add-ons and a stable production foundation; the centered diamond is the single configuration source of truth. The inverted direction suggests dropping a reusable scaffold into place without illustrating software literally.

## Brand brief derived from the repository

- **Brand:** Next Starter
- **Product:** A MIT-licensed, spec-aligned Next.js scaffold generator that assembles reusable applications from selected add-ons.
- **Core ideas:** modular assembly, standards alignment, production readiness
- **Letter:** no literal initial is required; the symbol prioritizes a recognizable independent silhouette
- **Palette:** Near Black `#1F1F21` and Warm White `#FAF9F6`
- **Wordmark:** Avenir Next Semibold with tightened tracking and compact inter-word spacing

## Usage

- Use `next-starter-symbol.svg` as the primary standalone mark.
- Use `next-starter-lockup.svg` when the name is needed.
- Use `next-starter-app-icon.svg` for square application surfaces.
- Use `next-starter-favicon.svg` at 16–32 px.
- Use the black or white symbol wherever only one ink or color is available.
- Preserve clear space equal to the width of the central diamond on every side.

The application uses this system for its shared wordmark, favicon, Apple touch icon, and web app manifest icons.
