# Security

Report suspected vulnerabilities privately to [zach@raintree.technology](mailto:zach@raintree.technology)
with the subject "Next Starter security report". Include affected versions,
reproduction steps, and impact. Do not include real credentials or customer data.
Do not disclose an unresolved vulnerability in a public issue.

Maintainers review reports as capacity allows. No response-time guarantee is offered.
Use the latest release and verify your deployment's database roles, provider
configuration, and access controls. Automated checks do not certify a deployment.

Keep actual environment files, local test credentials, and email action links out
of version control. Environment examples contain placeholders only.
